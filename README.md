## 👋 Salut

Je suis développeur, installé à Toulouse. Je passe mon temps entre **applications de bureau**, **outils pour artistes 3D**, **IA** et **création de contenu**. J'aime les petits outils bien finis, ceux qui font une chose et la font bien, et les projets qui me permettent d'apprendre quelque chose de nouveau.

En ce moment, je travaille surtout sur :

- 🎓 **LessonFolk** : apprendre l'IA avec une IA comme tuteur
- 🧊 **Voxel Shift** et **Moodcrate** : des apps pour les artistes 3D
- 🌧️ **Des vidéos d'ambiance** : cabanes sous la pluie, refuges dans le blizzard, cabines en orbite
- 🏠 **Un atlas des maisons** construit sur les données ouvertes françaises
